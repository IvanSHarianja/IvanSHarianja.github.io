Halaman statis yang dibangun dengan HTML, CSS, dan Bootstrap 5 — tanpa build step.

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan server statis apa pun dari folder ini.

## Struktur

```
index.html            halaman utama
assets/css/style.css  gaya kustom (token warna di :root)
assets/img/           foto profil dan tangkapan layar proyek (data contoh)
assets/*.pdf          CV
```
